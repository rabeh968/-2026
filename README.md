# أدوية المنزل (Home Medicines)

تطبيق ويب بسيط (ملف واحد، بدون خادم) لمعرفة الأدوية المتوفرة في المنزل وتواريخ انتهاء صلاحيتها.

- مسح ملصق العلبة بالكاميرا (OCR عبر Tesseract.js، يعمل داخل المتصفح) للإضافة أو الإزالة
- مراجعة البيانات قبل التأكيد، وإدخال يدوي عند الحاجة
- ألوان للحالة: منتهي / ينتهي خلال 90 يوماً / صالح
- البيانات محفوظة في المتصفح (localStorage) مع نسخ احتياطي واستعادة JSON
- `seed.json`: قائمة أولية؛ استوردها عبر زر «استعادة»

## النشر على GitHub Pages
1. أنشئ مستودعاً خاصاً أو عاماً وارفع هذه الملفات.
2. Settings ← Pages ← Source: **GitHub Actions**.
3. افتح الرابط من الهاتف ثم «إضافة إلى الشاشة الرئيسية».

> ملاحظة: الكاميرا تتطلب HTTPS (يوفره GitHub Pages). لا تضع في مستودع عام بيانات لا تريد نشرها.
